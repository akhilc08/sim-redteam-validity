## Phase 3c: best-of-n baseline (approved by the user 2026-11-22; run after Phase 3b)
- Why: Phase 3 shows the sim objective and real wins rising with rounds, but without a matched resampling baseline the rise could be extra draws on a noisy monitor plus the monotone best-so-far, not learning.
- Design (pre-registered before any 3c data): for each Phase 3 (and Phase 3b, budget permitting) pair, re-run the fixed round-0 strategy N times in simulation, where N matches the optimizer's rounds 1+ for that pair (about 6 per pair), same monitor/threshold/judge. Validate every sample the same way (replay + live rerun).
- Comparisons (live rerun primary):
  1. Real win rate: optimizer rounds 1+ vs resampled round-0 (Fisher, and pair-stratified CMH).
  2. Sim win rate: same contrast.
  3. Best-so-far objective curve vs best-of-k over the resampled draws (k = 1..N), averaged over runs.
- Budget: about $15-30 Bedrock per pair set, inside the remaining M7 caps.
